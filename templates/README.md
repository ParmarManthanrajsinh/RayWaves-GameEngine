# Templates

Project templates copied by the editor's New Project wizard. The wizard lists
them alphabetically and preselects `Simple2D`.

## Simple API (`Engine/rw.h`)

- `Simple2D/` - smallest complete game: one `rw::Level`, a sprite, a follow
  camera, and three editor-visible props. Start here.
- `Platformer2D/` - movement, jumping, and rectangle collision on top of
  `rw::Level`. `Assets/` is empty on purpose.

## Raw `GameMap` API

- `SlimeQuest/` - full multi-map demo (menu + level), enemies, audio, parallax,
  custom camera, and hot-reload state. The reference for larger 2D games.
- `ThirdPerson3D/` - 3D starter: orbit camera, capsule character, box collision,
  and a 3D editor gizmo.

## Conventions

- A template contains `project.raywaves`, `GameLogic/`, and optional `Assets/`.
- `AGENTS.md`, `.agents/skills/raywaves-game/`, `.clangd`, and `.vscode/` are
  generated by `ProjectManager` when a project is created or opened; they are
  not duplicated in each template folder.
- `.raywaves/tooling.ini` and `.raywaves/bin/rwcli.cmd` /
  `.raywaves/bin/rwcli` are generated to point agents at the packaged `rwcli`.
- `rw` templates export with `RW_GAME` from `Game.cpp`; raw templates use
  `RootManager.cpp` with the three `extern "C"` exports.
- Editor entities are registered with `rw::Level::Spawn` (simple API) or
  `GameMap::AddEntity` (raw API). Both are additive and safe to mix.
- Build artifacts and `.raywaves/` folders are stripped from distributions.
