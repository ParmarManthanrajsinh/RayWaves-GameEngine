# Templates

Project templates copied by the editor's New Project wizard.

- `Empty/` — minimal RootManager and map.
- `Platformer2D/` — camera, player, platform map.
- `SlimeQuest/` — full demo used by the editor build and smoke test.

A template contains `project.raywaves`, `GameLogic/`, and optional `Assets/`.
Build artifacts and `.raywaves/` folders are stripped from distributions.
